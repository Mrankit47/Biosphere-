# BioSphere 3D Assets

Place 3D model files (`.glb`, `.gltf`, `.fbx`) in this directory.
They will be served from the `/models/` path.

For assets used in the Virtual Lab:
- Ensure correct scale and orientation.
- Compact or optimize using compression utilities where possible (e.g. `gltf-pipeline`).
- Check the texture sizes to ensure good performance.
