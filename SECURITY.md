# Security Policy

## Supported Versions

We actively provide security patches and updates for the following versions of BioSphere:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of BioSphere, our students, and our platform users seriously. If you discover a vulnerability, please report it securely rather than opening a public issue.

### Disclosure Process

1. **Email Us:** Report your findings by sending an email to `support@biosphere.example.com`. Include as much technical detail as possible to help us reproduce the issue.
2. **Acknowledge Receipt:** A maintainer will respond to confirm receipt of your report within 48 hours.
3. **Investigation:** We will investigate and attempt to reproduce the vulnerability. We may reach out to you for more context or details.
4. **Resolution:** If confirmed, we will develop a patch and apply it. We aim to release security fixes within 14 business days of initial notification.
5. **Credit:** With your permission, we will gladly credit you in our security advisories or future release changelogs.
